# Sistem Manajemen Data Kost

## Deskripsi Program
Program ini merupakan aplikasi berbasis Java untuk mengelola data kost yang meliputi data mahasiswa, data kamar, dan data pembayaran. Program dibuat menggunakan konsep Object Oriented Programming (PBO).

## Alur Program
1. User memilih menu utama.
2. User dapat mengelola data mahasiswa.
3. User dapat mengelola data kamar.
4. User dapat mengelola data pembayaran.
5. Program berjalan terus menggunakan perulangan sampai user memilih keluar.

## Penerapan Konsep PBO
- Class: MahasiswaKost, Kamar, Pembayaran, dan Main.
- Constructor digunakan untuk membuat objek.
- ArrayList digunakan untuk menyimpan data.
- Encapsulation diterapkan menggunakan access modifier private.
- Percabangan switch digunakan untuk pemilihan menu.
- Perulangan digunakan agar program tidak berhenti sebelum memilih keluar.
